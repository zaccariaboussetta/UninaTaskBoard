# UninaTaskBoard

**UninaTaskBoard** è una piattaforma di collaborazione progettata per gli studenti universitari per organizzare e gestire attività all'interno di progetti (progetti di gruppo, preparazione esami, sviluppo software).

## 👥 Il Gruppo
Il progetto è realizzato da un gruppo di due persone per l'insegnamento di **Programmazione Object-Oriented** (A.A. 2025/2026) presso l'**Università degli Studi di Napoli Federico II (UNINA)**.

## 🚀 Stato del Progetto
- **Prima Consegna:** 07/06/2026 (Mock-up e Diagramma UML di progettazione EBC completati con successo).
- **Fase Attuale:** Sviluppo della logica applicativa e dell'interfaccia grafica.

## 🛠️ Tecnologie Utilizzate
- **Linguaggio:** Java
- **Interfaccia Grafica:** Java Swing
- **Database:** PostgreSQL (tramite pattern DAO)
- **Architettura:** Entity-Boundary-Control (EBC)

## 📌 Funzionalità Principali
- **Autenticazione:** Accesso sicuro per gli utenti registrati tramite credenziali.
- **Gestione Progetti:** Creazione di nuovi progetti e visualizzazione dei progetti a cui si partecipa.
- **Gestione Attività:**
    - Creazione di attività di tipo *Documentazione* o *Sviluppo*.
    - Definizione di descrizioni, scadenze e membri responsabili.
    - Aggiornamento dello stato di avanzamento (Non iniziata, In corso, Completata).
    - Inserimento di commenti per favorire la collaborazione.
- **Filtraggio:** Possibilità di filtrare le attività per stato, scadenza, membro assegnato o tipologia.
- **Reportistica:** Generazione di report per progetto con statistiche sulle attività e grafici riepilogativi (realizzati con JFreeChart o JavaFX).

## ⚠️ Note sull'Implementazione
In accordo con le specifiche della traccia e grazie al rispetto della roadmap di consegna (consegna intermedia del 07/06/2026):
- Il sistema **non include** la gestione dei file di codice e delle relative revisioni per le attività di sviluppo, come previsto dalle agevolazioni per chi rispetta i termini di consegna intermedi.
